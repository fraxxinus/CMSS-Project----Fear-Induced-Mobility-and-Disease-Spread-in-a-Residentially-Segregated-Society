# Fear-Induced Mobility and Disease Spread in a Residentially Segregated Society

In this project we used the basic principal of Schelling segregation and apply an infection after the segregation.

The report.pdf describes the principal and our findings from the currently tested variables.

The simulation, testing and chart generation is produced by the simulation.ipynb. 
The requirements.txt can be used with Python 3.14.2 to replicate our results.
